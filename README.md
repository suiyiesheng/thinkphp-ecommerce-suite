# ThinkPHP 电商套件

一个基于 ThinkPHP 8 开发的电商系统基础框架，用于学习和接单演示。

## 功能特性
- 商品管理（增删改查）
- 分类管理（规划中）
- 订单管理（规划中）

## 技术栈
- ThinkPHP 8
- PHP 8.1
- MySQL 5.7+
- Bootstrap 5

## 本地运行
1. 克隆项目：`git clone git@gitee.com:你的用户名/thinkphp-ecommerce-suite.git`
2. 安装依赖：`composer install`
3. 配置 .env：`cp .example.env .env` 并修改数据库配置
4. 访问：`http://tp.local`
